🃏 Cards — Soft UI

Card com Soft Shadow

Este card usa neumorphism com sombras suaves que criam sensação de elevação. Passe o mouse para ver o efeito hover.

Elevação Tátil

Bordas arredondadas (20px) e sombras duplas (interna + externa) simulam profundidade física, convidando ao toque.

Transições Suaves

Todas as transições usam cubic-bezier para movimentos naturais. Hover = lift + shadow increase.
